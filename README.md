# 🦸 Página de Super-Herói

Página web simples desenvolvida para praticar a criação e organização de conteúdo utilizando HTML.

## 📌 Sobre o projeto

O projeto apresenta uma página dedicada a um super-herói, utilizando elementos HTML para estruturar as informações e o conteúdo visual da página.

## 🛠️ Tecnologias

- HTML5

## 🎯 Objetivo

Praticar a utilização de elementos HTML e a estruturação de uma página web.

## 🚀 Como executar

Abra o arquivo HTML em um navegador.
